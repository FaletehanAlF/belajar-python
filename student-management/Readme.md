# Student Management

Student Management adalah program sederhana menggunakan Python untuk mengelola data siswa.

## Features

- Lihat semua siswa
- Tambah siswa
- Cari siswa
- Update siswa
- Hapus siswa

## Technologies

- Python
- JSON
