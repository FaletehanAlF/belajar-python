# Student Management

Student Management adalah program sederhana menggunakan Python untuk mengelola data siswa.

## Features

- Lihat semua siswa
- Tambah siswa
- Cari siswa
- Update siswa
- Hapus siswa

## Technologies

- Python
- JSON

## Project Structure

```text
student-management/
├── app.py
├── students.json
└── README.md

How to Run

Masuk ke folder project:

cd student-management

Jalankan program:
python app.py

Menu:
=== STUDENT MANAGEMENT ===
1. Lihat semua siswa
2. Tambah siswa
3. Cari siswa
4. Update siswa
5. Hapus siswa
6. Keluar
